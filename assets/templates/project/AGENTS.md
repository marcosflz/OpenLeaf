# AGENTS.md: notas del proyecto para el asistente IA

El asistente LaTeX de LaTeX Studio lee este archivo en cada conversación.
Úsalo para contarle cómo quieres que trabaje en **este** documento. Puedes
editarlo o borrarlo cuando quieras.

## Documento
- Archivo principal: `main.tex`
- Motor: pdflatex (cámbialo a xelatex o lualatex si usas fuentes del sistema)
- Idioma del texto: español

## Estilo
- Cambios mínimos: no reformatees ni reescribas lo que no te pida.
- Conserva el tono y la terminología del documento.
- Prefiere paquetes estándar de TeX Live; avisa antes de añadir uno nuevo.

## Convenciones del proyecto
- Figuras en `figuras/`, una por archivo.
- Etiquetas con prefijo: `fig:`, `tab:`, `sec:`, `eq:`.
