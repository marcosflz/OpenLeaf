# P2-INST-1 — Instalador con motor LaTeX automático (2026-10-24)

- **Tarea:** P2-INST-1 del plan `docs/kb/changes/PLAN-0.2.md`.
- **Territorio tocado:** `installer/latex-studio.iss`, `installer/build.ps1`,
  `docs/release.md`, `docs/kb/architecture/05-instalador.md`, este informe.
- **Entorno:** Windows 11 (10.0.26200), Inno Setup **6.7.3**
  (`%LOCALAPPDATA%\Programs\Inno Setup 6\ISCC.exe`), PowerShell 7, red doméstica.
- **Resultado global:** **PASS** en compilación y en los caminos silenciosos probados;
  quedan límites documentados (página interactiva no ejercitada visualmente, payload real
  no disponible en este repo, ruta no ASCII).

## 1. Qué se implementó

`installer/latex-studio.iss` incorpora:

1. Página **Motor LaTeX** (solo perfil ligero) con tres opciones:
   - usar `{app}\tex\bin\windows\latexmk.exe` si existe (no se modifica);
   - descargar TinyTeX-1 si no existe `{app}\tex`;
   - no instalar ahora (aviso accionable).
2. Descarga fijada:
   - URL: `https://github.com/rstudio/tinytex-releases/releases/download/v2026.10/TinyTeX-1-windows-v2026.10.exe`
   - SHA-256: `36c329c644683d981a668419d13c8804696e2816ae4d287ad755788fee231a31`
   - tamaño: `73701889` bytes.
   - `CreateDownloadPage` en interactivo; `DownloadTemporaryFile` en silencioso.
3. Extracción del SFX 7z con `-y -o"{app}"` → `{app}\TinyTeX`, y `RenameFile` a
   `{app}\tex`. Nunca se sobrescribe un `tex` existente.
4. Bootstrap con log, timeout y salida capturada:
   - `tlmgr update --self`
   - `tlmgr install synctex biber`
   - `tlmgr install beamer pgf grfext titlesec enumitem preprint marvosym roboto fancyhdr tools babel-spanish babel-english`
   - tiempos máximos: 900 s extracción, 900 s `update --self`, 1200 s binarios,
     1800 s paquetes base.
   - runner temporal `{tmp}\lsx-run.ps1` con `WaitForExit(ms)` y `taskkill /PID /T /F`
     (devuelve `124` al vencer).
5. Verificación de `latexmk.exe`, `synctex.exe` y `biber.exe`; log en
   `{app}\logs\tex-bootstrap.log`; marcador `{app}\tex\.lsx-bootstrap.json` con estado
   `ok`/`partial`.
6. Un fallo de red/URL/hash/extracción/`tlmgr` **no aborta**: se registra, se avisa y se
   limpian restos parciales cuando es seguro. Un `tex` del usuario no se borra.
7. Guarda para rutas no ASCII: TinyTeX/`latexmk` falla en rutas con `ñ` u otros caracteres
   no ASCII; el instalador desactiva la descarga, avisa y permite elegir una carpeta ASCII
   o usar `/DBundledTex`.
8. `/DBundledTex` compila sin página ni descarga y solo verifica el `tex` incluido.
9. `installer/build.ps1` documenta el nuevo comportamiento; no cambia el perfil de CI.

## 2. Compilación

El repo no tiene `dist\latex-ide` ni `agent\opencode.exe`, así que se montó un payload
temporal **fuera del repo** en `%TEMP%\lsx-p2inst1`:

```
%TEMP%\lsx-p2inst1\
  installer\latex-studio.iss   (copia)
  installer\latex-studio.ico   (copia)
  dist\latex-ide\latex-studio.exe (dummy)
  dist\latex-ide\VERSION
  dist\latex-ide\agent\opencode.json
  dist\latex-ide\assets\skills\README.md
  dist\latex-ide\tex\bin\windows\{latexmk,synctex,biber}.exe (dummy, solo /DBundledTex)
```

Comandos:

```powershell
ISCC.exe /Qp "%TEMP%\lsx-p2inst1\installer\latex-studio.iss"
# exit 0

ISCC.exe /Qp /DBundledTex /DOutputName=LaTeX-Studio-Setup-Bundled `
  "%TEMP%\lsx-p2inst1\installer\latex-studio.iss"
# exit 0

# Validacion del wrapper de build (copia temporal con payload dummy):
pwsh -NoProfile -File "%TEMP%\lsx-buildps1\installer\build.ps1" -SkipBuild
# "Successful compile (0,906 sec)"; exit 0
```

1. **Payload real completo**: no hay `dist\latex-ide` ni `agent\opencode.exe` en el repo.
   Se compiló con un payload dummy; falta compilar el Setup real con `cargo xtask dist` y
   `agent/opencode.exe`, y probar la app real.
2. **Página interactiva**: no se recorrió el wizard con ratón/teclado ni se capturó la
   página “Motor LaTeX”/barra de progreso. La compilación valida las APIs
   (`CreateInputOptionPage`, `CreateDownloadPage`, `CreateOutputProgressPage`) y el

3. **Cancelación**: no se automatizó el botón Cancelar de la página de descarga ni el

4. **Sin red física**: se simuló con una URL local cerrada, no desconectando el adaptador.
5. **Instalación con el `.exe` real de la app**: el payload dummy no arranca la app ni
   compila una plantilla; el motor sí se probó con `latexmk`/`synctex`/`biber` reales.
6. **Gates Rust**: no se tocó código Rust. `cargo fmt --check` falla por archivos de
   otros territorios (`app/src/main.rs`, `crates/core/src/config.rs`), no por este cambio;
   no se ejecutaron `clippy` ni `nextest` para no interferir con otros streams.

## 6. Riesgos y pendientes

- **Ruta no ASCII**: limitación real de TinyTeX (probada con `ñ`). El instalador avisa y
  no descarga, pero un usuario con nombre de Windows acentuado y la ruta por defecto
  (`%LOCALAPPDATA%\LaTeX Studio`) no podrá usar TinyTeX. Mitigación: carpeta ASCII o
  `/DBundledTex`; a futuro, P2-INST-2 podría instalar el motor en una ruta ASCII y usar
  `advanced.texBinOverride`.
- **PowerShell**: el runner usa `-ExecutionPolicy Bypass`; una política de grupo que lo
  bloquee degrada el bootstrap a aviso. La app se instala igual.
- **Antivirus/SmartScreen**: el SFX de 74 MB y el `.exe` sin firmar pueden tardar o
  avisar; hay timeout de extracción.
- **Cancelar durante `tlmgr`**: puede dejar un `tex` parcial. Una reinstalación lo detecta
  y no lo borra; la app puede auto-instalar paquetes faltantes.
- **Desinstalación**: el perfil ligero conserva `tex` (puede tener paquetes del usuario);
  solo `/DBundledTex` lo borra. Está documentado en `docs/release.md`.
- **CI**: `.github/workflows/installer.yml` sigue comentando que el usuario copia `tex\`;
  el comportamiento del workflow es correcto, pero el comentario queda obsoleto. No se
  tocó `.github/` por territorio; conviene que el orchestrator lo actualice.
- **Payload real**: falta ejecutar `pwsh installer\build.ps1 -SkipBuild` sobre el
  `dist\latex-ide` real (con `agent/opencode.exe`) para publicar el asset de 0.2.
- **Reintento desde la app**: el aviso del instalador remite a volver a ejecutar el Setup.
  El reintento guiado desde Ajustes → Compilación es P2-INST-2, fuera de este territorio.
