## Qué se comprobó de verdad

- El diálogo abre con `Ctrl+,` y mediante el hook de QA; la navegación lateral cambia de
  sección sin perder el borrador.
- El tema claro se aplica a árbol, editor, PDF, chat, problemas y status bar; el chat ya no
  tiene una paleta oscura fija.
- El acento se previsualiza y se restaura al cancelar; el hex inválido no cierra el diálogo.
- La sección IA muestra el error de ejecutable ausente, deshabilita los comandos que lo
  necesitan y ofrece “Abrir carpeta agent/”.
- Los permisos del chat y de Ajustes comparten `ask`/`project`/`all`; `Settings::validate`
  ya no resetea `project`/`all` a `ask`.

## Limitaciones

- No hay `agent/opencode.exe` en el repo; `auth list`, `models` y `auth login` no se
  ejecutaron contra el binario real en esta máquina. El parser y el manejo de timeout están
  cubiertos por tests; la prueba live queda para G2.5 con el binario instalado.
- Los cambios de `ai.autoStart`, `port`, `showReasoning` se aplican al reiniciar el chat
  (el panel se construye con `ChatPanelConfig`); el picker de modelo/agente sí persiste.
- El campo de modelo es texto/selector; no se consulta `/config/providers` en vivo desde
  Ajustes (la lista sale de `opencode models`).
- El botón “Conectar proveedor” abre una consola; la auth nativa por `/provider/auth`
  (P2-AI-3) queda para 0.3.

## Bugs encontrados y corregidos en la ola

- **Permisos:** `validate()` solo aceptaba `ask`/`auto`; el chat escribe `project`/`all`.
  Corregido en `crates/core/src/config.rs` + test de regresión.
- **Tema claro:** el chat usaba una paleta oscura fija; ahora resuelve tokens del tema.
- **Dock:** las fracciones por defecto se ajustaron para que PDF/chat no recorten sus
  cabeceras en 1200–1400 px.
