# P2-UI-3 — Ventana, menús y persistencia del chat (2026-10-24)

## Alcance

- Persistencia de geometría de la ventana (`ui.window`: x, y, width, height, maximized).
- Restauración con clamp a una pantalla visible (si la posición guardada ya no existe, centra).
- Barra de menús de escritorio: Archivo · Ver · Herramientas · Ayuda.
- Título de ventana con proyecto y marca `•` si hay documentos sucios.
- Cierre seguro: `Window::on_window_should_close` + diálogo Guardar / Descartar / Cancelar.
- Atajos visibles: F1 abre la lista; Ctrl+B compila; Ctrl+S guarda; Ctrl+Q sale.
- P2-AI-2: el picker de modelo/agente del chat persiste en `ai.model`/`ai.agent`.
- Se retiró el botón de demo de permisos de la toolbar y de la paleta.

## Limitaciones / seguimiento

- El cierre con cambios sin guardar no se ha probado aún con un clic real en la X (sí el
  camino de guardado y el registro del hook). Queda para QA manual (G2.5).
- Los menús usan textos en español directamente; falta moverlos a `locales/es.yml`.
- El `Ctrl+S` global convive con el binding del editor; verificar que no se dispare dos veces
  en una prueba manual.
- La ventana recuerda geometría, pero no el monitor por ID; si el monitor cambia, se centra.
